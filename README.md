# Council Scorecards (retired)

**This site is retired.** Its grades are no longer published. Every page now redirects to its
replacement on [Berkeley Council Watch](https://ericdf.github.io/berkeley-council-watch/), which
publishes the underlying record (votes, authorship, meeting time and commitments) for each member
and for the Council, with no grades. Analysis is published by the
[Berkeley Decision Project](https://ericdf.github.io/berkeley-decision-project/).

The redirect pages stay here so that existing links keep working. The site's earlier pages remain
in this repository's history.
